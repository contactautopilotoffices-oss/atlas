# Co-brand assets

Autopilot: the existing approved repository wordmark in `airoli-rtp/brand/autopilot-wordmark-white.png`.

Flipkart: current header assets served by [Flipkart](https://www.flipkart.com/), downloaded 2026-11-21. Original blue symbol and black wordmark are kept intact on a white plaque:

- `https://rukminim2.flixcart.com/fk-p-flap/104/88/image/d2ecfddf891a3922.png?q=100`
- `https://rukminim2.flixcart.com/fk-p-flap/276/108/image/31f7e3af490c225f.png?q=100`

Palette: official home CSS variables `--midnight-blue: #2A55E5` and `--golden-yellow: #FFC200`. Logos belong to their respective owners; their use here identifies the requested Autopilot presentation for Flipkart.

Sound: `twin-arrival.mp3` generated with the configured ElevenLabs Sound Effects account. Prompt/model metadata is in `sound.json`; no credentials are included. `selection-tick.mp3` reuses the project's existing ElevenLabs-generated interface tick. Playback starts on a user gesture, with a visible mute control and a stored session preference.

Mapbox: `mapbox-logo.svg` is the unmodified official vector from the Mapbox GL JS 3.10.0 stylesheet. Satellite imagery is requested from Mapbox at runtime using the existing project configuration, with visible Mapbox/OpenStreetMap/Maxar attribution. Native satellite images used in private Blender reviews are excluded from public model packages.
