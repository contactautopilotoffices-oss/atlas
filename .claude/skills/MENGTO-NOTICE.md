# Skills from MengTo/Skills

These skills are copied from https://github.com/MengTo/Skills
(MIT License, copyright 2026 Meng To; the licence travels in each folder as
`LICENSE-MengTo-Skills`):

- build-threejs-scroll-worlds (one 3D world driven by native scroll)
- 3d-virtual-tour (guided and free walkthroughs, floor-plan navigation)
- 3d-sky-background, 3d-sky-rays (camera-correct skies, sun shafts)
- 3d-high-poly-models, 3d-high-resolution-textures, 3d-retina-resolution

Only the SKILL.md files and their references/ folders are kept; the
scroll-worlds demo and its images are left in the source repository.

They sit beside our own archviz-* skills, which set the quality bar for
Blender renders (archviz-blender-photorealism, archviz-quality-bar, ...).
